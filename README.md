**Coating Benchmark & Performance Dashboard**
**Overview**

A data-driven benchmarking dashboard designed to evaluate and compare commercial paint and coating products using standardized laboratory testing, weathering data, and product pricing.

The dashboard allows users to select products and relevant tests, assign custom weights based on application requirements, and dynamically compare performance across multiple categories. It also integrates historical weathering results and test images to provide both quantitative performance analysis and visual comparison.

The goal is to turn a traditionally manual benchmarking and reporting process into a standardized, scalable, and interactive decision-support tool for R&D, marketing, and commercial applications.

**Key Features**

Standardized benchmark and weathering test data

Dynamic product and test selection

User-defined test weighting and scoring

Product-to-product performance comparisons

Weathering performance and visual degradation analysis

Performance-to-price analysis

Historical product performance database

Automated image linking through Google Drive and Google Apps Script
